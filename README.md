A make.fun entry for **One-Line Roast: The Gadget You Use Every Day** (`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`).

The program writes a single line — a roast of the phone that dies at 4pm and dims itself like it is clocking out early — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes exactly one line (153 characters, no trailing newline) to `/output/entry.txt`, deterministically: the same bytes on every run, from any working directory. No input, no network, no secrets.
